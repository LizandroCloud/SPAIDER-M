About
=====

SPAIDER was developed between 2018 and 2025, originating from research conducted for a doctoral dissertation titled "An adaptive sequential wavelet-based algorithm developed for dynamic optimization problems" <https://doi.org/10.1016/j.compchemeng.2018.11.007>. The initial goal of the project was to develop adaptive strategies integrated with the single shooting algorithm. Over time, additional features were implemented to improve usability and computational efficiency, enabling faster, more robust problem-solving. After extensive testing and validation, the first official release of SPAIDER (version 0.1.0) was published in 2026.
