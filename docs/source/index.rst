SPAIDER **Documentation**
================================
**Sequential and Parallel Algorithms Integrated to Differential Equation Routines**

Sequential and Parallel Algorithms Integrated to Differential Equation Routines (SPAIDER) is a collection of Matlab/Python scripts tailored to solve dynamic optimization and optimal control problems. It provides single-shooting (control vector parameterization) and multiple-shooting algorithms. The main features of SPAIDER include:

- Adaptive strategies for control-vector parameterization.
- Symbolic environment for modelling of differential and algebraic equations (DAEs).
- Interfaces with external solvers such as Aspen Hysys, Aspen Plus and EMSO.
- Integration with Machine Learning Models.
- Python and Matlab Interfaces.
